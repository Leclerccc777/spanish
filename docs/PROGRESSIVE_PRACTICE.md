# A1–B2 递进练习（核心与巩固）

建设日期：2026-10-13。每级 3 个核心包 + 3 个巩固包，共 24 包、96 道受控题、24 篇原创短阅读和 24 项个人表达任务。它是一条补充训练路线，未覆盖各级全部能力要求；现有 32 单元和 6500 词库继续按原规则学习。

每包先用情景说明“为什么要这样说”，再读例句和规则。答题时可选择“需要一点提示”，先找人称、数量、时间或话语立场等线索；翻题后提示收起。答完尝试合上材料开口说一句，再写自己的表达，逐步减少对例句的依赖。集中订正沿用同一思路提示；查看提示本身不写成绩、清除错项或开放后续包。重音 / ü / ñ 的近似拼写得到专门提醒，但仍需准确写出才算答对。

24 篇短文可在阅读页展开中文大意：先读西语，必要时借助中文理解整段，再回到原文找对应句子。换包或刷新时默认收起；作答页只展示原西语短文和词语提示。翻译只帮助理解，不保存成绩或开放尚未达标的练习；译文为原创，待教师审稿。

每篇另有三组可选词组解释：先找原文里的词，再看本句意思、代词指向或搭配，而不是逐字翻译。24 段个人对话让你替换身份、作息、经历、需求与观点；完成后收起提示，再换到每包提供的新场景重新说。例如从买衬衫换成买书时，不只换名词，还要检查指示词和宾语代词；从周一宣布、周三转述换成周五宣布、周一转述时，重新判断“次日”是哪一天。

词组解释和对话都默认收起，不写成绩，也不开放锁定包。自己的对话或迁移表达可记入原有草稿；保留当前和上一保存版本。原自查仍对应写作任务，新增“说完检查”用于手工核对本次情景，不自动评分。新增材料为原创，待教师审稿。

## 从短句到文章的建议顺序

先完成四步入门，并在名词三步练习中练熟冠词与性数，再进入补充路线。每级按下方顺序循环“理解 → 自己说 → 换情景”，不按日历赶级：

- A1：身份与位置 → 问候礼貌 → 名词配合 → 日常动作 → 疑问否定 → 喜好理由。
- A2：周末经历 → 购物请求 → 比较计划 → 日常作息 → 求助预约 → 出行准备。
- B1：背景事件 → 建议目的 → 观点依据 → 关系从句 → 情感愿望 → 过去先后。
- B2：让步限制 → 假设方案 → 信息转述 → 特指与待定 → 被动报告 → 项目评价。

24 篇短文先给一个具体阅读问题，学习者回答后可展开原文依据和中文解释。问题要求定位信息、连接两句话或保留原文的不确定性；它们不替换原四题，查看参考不计成绩。

## 每包怎么练

1. 读中文规则、双语例句和复用词，先说出句子的意思。
2. 做辨析题，判断为什么选这个词形或结构。
3. 填写指定词形，再把错误句改成完整句子；重音和 ñ 不省略。
4. 阅读原创新短文，根据内容回答，避免把假设、计划或转述当成事实。
5. 完成四题后保存结果，再按句型起点写自己的表达。A1 约 3 句、A2 约 4 句、B1 约 5 句、B2 约 6–8 句，逐步增加理由、语境和信息关系。
6. 保存草稿后可对照原创范文；按三个自查问题修改自己的内容，再保存。建议请教师或同伴给出真实反馈。

每包四题至少答对三题（75%）后继续满足前置条件的包；各级内容均可预览。开放状态使用沿 previousId 回溯的全部前置包历史最佳分，之后遗忘或退步不会锁回已经开放的包，但新的错项仍会留下。个人表达不自动评分，保存草稿也不会开放下一包。路线独立于主课程的词汇确认、单元开放和每日打卡。

## 内容边界与依据

参考引用沿用对应课程的 Cervantes PCIC A1–A2 / B1–B2 语法、主题清单与 DPD gustar 等已有记录。本轮没有重新访问官方正文，也没有扩大基础词条审核结论。新增题目、短文、中文解释和范文为原创，待教师审稿；级别是本站教学顺序，不是官方逐题定级。

ser / estar 不按“永久 / 临时”机械区分；hay 包只练典型存在句。过去时由背景 / 事件语境决定，不按动作持续时间硬分。aunque 包明确指定事实断言与假设的对照，同时说明真实语用还受共享信息与立场影响。间接引语的时态和时间词依据明确转述日期，不声称所有转述都要机械后移。

受控题核对有限的指定答案，支持 NFC、大小写、连续空格、开头 ¿ / ¡ 与句末标点；不推断任意同义改写的语法正确性。B2 假设题显式接受 tuviera / tuviese。自由表达只保存草稿并提供量规与范文，不能据此判断 CEFR 等级。

没有新增真人音频、听说录音评估、完整四技能考试或教师反馈服务。小程序仍需微信官方编译与真机验收。

## 集中订正与表达修订

分级列表中的“集中订正”可按等级抽取实际错项，每轮先安排最多 12 个不同错项。答错本轮再出现一次；答对后立即移除对应错项，首次正确率保留首答结果。订正不修改完整学习包的最佳分、次数或课程开放状态；原包未达标时仍须完整重练。

个人表达保存当前文本与上一保存文本，每份最多 3000 字符；只保留一个历史版本，避免无限增加备份体积。相同文本重复保存不增加版本数。“恢复上一保存版本”会交换当前和上一文本，可再恢复回来；“撤销未保存修改”返回当前已保存文字。

自查问题可手工勾选并反选；修改文字时先保存，保存新文字会清空旧勾选，提醒重新审查。自查只表示学习者完成检查，不判定语法或能力；它不改变得分、打卡或课程开放状态。旧纯文本草稿导入后保留原文字，补充版本与空自查信息。
