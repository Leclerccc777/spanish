# 持续建设路线

每轮完成一项可使用、可验证的改进，并提交到 GitHub。优先让零基础学习者知道今天做什么、为何做，再逐步补齐 A1–B1 的练习材料与能力反馈。

## 已完成的本轮：四步入门与一年路线

- 首页优先入口；5–6 分钟微课讲发音、重音、阴阳性、性数配合，含常见例外和 16 道原创规则题。
- 52 周 A1–A2–B1 安排与第 365 天复盘，连接已有 24 个语法/表达单元；周自检及基础进度可备份。
- 课程按实际练习解锁，日历不自动提高等级；选择题不包装成发音或交际能力评分。

## 下一轮优先：A1 词汇真正连着用

先校对最常用的一小批名词，为已核对条目补上冠词、阴阳性、复数及短语；增加“选冠词 → 改形容词 → 补完整句”练习。每次只处理可核验的一批，不把 6183 个英中中转提示一并标为已审定。保留原词 ID、来源、审核范围、许可与待审核状态。

## 后续按部分搭建

1. **A1 核心动词**：ser / estar / hay、规则现在时、gustar；增加辨析、填空、纠错和个人化句子，支持错项复习。
2. **第 1–4 周学习包**：把年度建议补成每天的小任务，在已学词汇上增加受控短句、短阅读和角色对话；逐周核对内容，确保新手可执行。
3. **发音与听力**：引入适合 A1 的、版权和使用方式明确的音频及文字稿，再提供听辨、跟读、自录音回听。音频先解决来源、播放及真机兼容，再考虑评分。
4. **A2 叙述与交际**：过去时、请求、购物/出行情景，复用旧词，不断修订表达；结合 13–28 周逐包完善。
5. **B1 综合能力**：经历、理由、建议、观点与连贯文本，结合 29–48 周逐包完善；采用明确评价量规，最终通过教师或外部四技能评估判断水平。
6. **学习可靠性**：保护旧备份、存储失败和断档后的恢复体验；再根据需求接入账号与同步，并在微信开发者工具和真机持续验收。

6500 个词元是可练习的数据范围，词量和打卡不能直接等同 CEFR 等级。一年为规划窗口，学习负担、输入材料和反馈质量都需要根据个人进展调整。
